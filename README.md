# Science & Tech - Material

Welcome to the **Science & Tech (Cycle 27)** repository. This repository contains learning materials, code samples, guides, and practical tasks designed to guide you through a comprehensive software engineering curriculum.

---

## 🎯 Program Overview

The **Science & Tech** program is divided into two sequential phases: **Science** followed by **Tech**.

```
[ Phase 1: Science ]  ─────────►  [ Phase 2: Tech ]
Computer Science Foundations       Applied Web Development (.NET)
```

---

## 🧪 Phase 1: Science (Core Foundations)

The **Science** phase focuses on building deep computer science foundations, clean code practices, and strong problem-solving skills:

- **Object-Oriented Programming (OOP):** Core paradigms, encapsulation, inheritance, polymorphism, and abstraction.
- **Data Structures & Problem Solving:** Essential data structures and applying them to solve algorithmic problems efficiently.
- **Software Design Principles & Patterns:**
  - **Design Principles (SOLID):** Writing clean, maintainable, decoupled, and extensible code.
  - **Design Patterns:** Creational, structural, and behavioral design patterns to solve common architectural problems.

---

## 🚀 Phase 2: Tech (Applied .NET & Web API)

The **Tech** phase takes the solid engineering foundations established in the Science phase and applies them to modern industry technologies using the .NET ecosystem:

- **.NET Fundamentals:** Modern .NET platform features, dependency injection, and project configurations.
- **Web API Development:** Designing, building, and documenting RESTful Web APIs using ASP.NET Core.
- **Backend Architecture & Best Practices:** Data persistence, middleware, validation, error handling, and scalable API architecture.
